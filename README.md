# 🚗 MM Viajes — Landing page

Landing page for **MM Viajes**, a private passenger transport service in Córdoba, Argentina: airport transfers, events, business trips and special occasions.

🔗 **Live:** https://tomasmalvissi.github.io/MMViajes/

## ✨ Highlights

- Single-page, responsive layout with no frameworks or build step.
- Clear call to action: direct contact through **WhatsApp**.
- Services section (airports, events, business, vacations, health appointments, special occasions).
- Lightweight and fast: one HTML file, one stylesheet.

## 📁 Structure

```
index.html
styles/styles.css
assets/
```

## ▶️ Running locally

Just open `index.html` in a browser.
